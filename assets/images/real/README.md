# Ảnh thật Datbike Quantum S1

Đặt ảnh thật (có QUYỀN SỬ DỤNG) vào thư mục này với tên:

    quantum_s1.jpg      (ưu tiên)  — ảnh nghiêng 3/4, nền sáng/trong, tỷ lệ ~16:9, ≥ 1376×768
    quantum_s1.png      (dự phòng)

App tự dùng ảnh này nếu có. Nếu chưa có, app hiển thị ảnh MINH HỌA cũ
(`assets/images/bike_hero_3d.jpg`, do AI tạo, KHÔNG phải ảnh xe thật) kèm nhãn
"ẢNH MINH HỌA" để không gây nhầm lẫn.

Không dán ảnh lấy từ web nếu chưa có giấy phép. Ghi nguồn + giấy phép vào
`assets/images/real/CREDITS.md`.
